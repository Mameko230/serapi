# Serapi Web Workspace v3 — 方向原型

可交互 Web 原型，用于验证“长段、十几条命中、词典不臃肿、工具栏入口不丢”的布局。
不是生产 UI；主分支未改动。

## v3 新增

### 中栏行可读性

- 采用**行级配对**：每一行同时承载原文/译文，行高取两侧较高者；
- 一侧文本换行只把这一行撑高，**不会把后面的行推歪**；
- 行号 gutter 更清晰，等宽数字 + 当前行主色；
- 行高 36px 起，行内 padding；偶数行极淡斑马底；
- 当前行同时在原文/译文两侧高亮，左侧主色标记；
- QA 行单独用极淡红底 + 波浪线；
- hover 整行高亮，不再靠两侧各自滚动同步。

## 这版解决的四个问题

### 1. 长段：固定双栏 + 同步滚动

- 中栏固定为 **原文 40% / 译文 60%**，不再上下堆。
- 左右各自滚动，但默认按比例同步；可关闭同步。
- 每侧带行号 gutter；12 行示例在截图里完整可见。
- 译文更宽、更高对比；原文次要色。
- 页面不再随段长改变骨架。

### 2. 语境栏：胶片带，不是五张卡片

- 单行五段：前2 / 前1 / 当前 / 后1 / 后2。
- 用透明度和一条左侧主色标记表达层级；当前项才高亮。
- 默认高度约 54px；收起后只留标题行。
- 不重复显示当前译文（译文就在下方），减少视觉重量。
- hover 才显示完整原文；不占正文空间。

### 3. 右栏：固定骨架 + 命中列表内滚 + 详情固定

右栏从上到下固定：

```text
QA 摘要（最多约 3 条，错误优先）
TM/TB 列表（内部滚动，可筛全部/TM/TB）
选中命中详情（固定，不随列表滚走）
段信息（固定底部）
词典短语卡（仅选中词）
```

- 20 条命中时列表自己滚，QA、详情、段信息不会被顶走。
- 默认自动选中第一条命中，所以详情始终有内容。
- 详情显示：匹配率、来源/审校/时间、原文/译文、插入提示。
- 列表行保持单行两列，不靠“展开全部”解决密度。

### 4. 词典：选词驱动，不扫描全文

- 只显示当前选中/悬停的 **一个词条**；
- 最多 1–2 个义项，不列原文所有出现位置；
- 没有选中词时显示“选中词查询”，高度约 64px；
- “查看全部”打开完整词典浮层；
- 优先级：个人库 > ja-zh > ja-ja > 日英兜底；**不含 TB**。

## 原来的主面板按钮入口去哪了

没有丢，分成三层：

1. **顶部工具条**：资产/词典、引擎、账号、主题、Tag 规则、设置；
2. **“更多”菜单**：快捷键、主题与背景、编辑器字号、Tag 显示长短、查找替换；
3. **命令面板 / 快捷键**：搜索段、术语、记忆，或执行命令；保留原有 Ctrl+D / Ctrl+K / Ctrl+H 等。

原型里点这些按钮会弹 toast，表示入口存在；正式迁移时它们分别绑定现有 Qt 端口。

## 交互

- 点击/↑↓ 切换段
- 段筛选：全部 / 关注 / 审校 / 完成
- 点击 QA：定位并在译文行内标出
- 点击命中：详情固定在下方更新；TM/TB 可筛选
- 语境收起/展开
- 亮/暗主题
- 编辑译文（contenteditable，本地原型）
- 更多菜单、命令入口、toast 反馈

## 与生产架构的距离

如果选这个方向，迁移不是换皮：

- Web 层：本原型的三栏/双栏/固定右栏/命令条
- Python 宿主：保留 memoQ bridge、WritePolicy、TM/TB/QA/词典数据源
- 通信：QWebChannel 或本机回环 HTTP
- memoQ 页面仍由 QWebEngineView 承载；新 UI 只替换 Serapi 自己的工作区
- 现有按钮入口迁移到顶部工具条 + 更多菜单 + 命令面板，不删功能
