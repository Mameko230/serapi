## 1. 实时 QA

### 实现

- `app/lint.js`：纯函数规则引擎，无 DOM、无网络、无写操作。
- `app/qa_rules.json`：规则集外置；用户开关写入 `~/.memodesk/qa_rules.json`。
- `app/qa.py`：配置合并、TB 术语对提取、lint 负载/结果整理。
- `app/qa_ui.py`：右栏「实时 QA」面板 + 行内标记 + 规则菜单。
- `app/qtedit.py`：`set_qa_marks()` 只使用 `ExtraSelection`，不碰文档/token/dirty；与 TB 术语高亮合并，不互相覆盖。
- 触发：`_on_editor_contents_changed()` 在确认“真实编辑”后 debounce；切段时清除旧标记并重跑。
- 展示：右栏汇总可点击定位；行内波浪下划线 + 淡黄底；绝不自动改文。

### v1 规则

1. 数字一致性（原文数字未出现在译文 / 译文多出数字）
2. Tag 差额（按 id+kind 计数）
3. 全半角数字混用（同一译文行）
4. TB 术语未采用（只检查同时有源/目标术语的 TB 命中）
5. 行长/行数（复用编辑器现有 `_line_limit` / `_max_lines`）

### 测试

- `tests/test_lint.js`：逐规则命中、规则关闭、零误报 fixture。
- `tests/test_qa.py`：配置/负载/结果整理。
- `tests/test_qa_ui.py`：真实 token → lint 回调 → 面板/行内标记。

## 2. 游戏语境增强

### 实现

- `app/context.py`：前后段提取、key/speaker 解析、角色既往译法聚合（只用已缓存段）。
- `app/context_ui.py`：主编辑区下方常驻语境栏，显示当前段前后各 2 段；当前行高亮。
- `app/seg_model.py`：新增 `all_rows()` 读侧快照。
- 切段/段列表刷新时更新；`segment_info` 的 contextId 到达后补显示。
- 只读，不发请求；speaker 不可解析时显示“—”。

### 未做（交接文档允许砍掉）

- Patch 历史版本 diff：memoQ 读侧没有稳定的历史版本 API，未硬做。
- 项目 TM 按角色聚合：没有稳定的角色/说话人 API；当前实现为“本会话已缓存段”聚合，避免给服务器增加查询。

### 测试

- `tests/test_context.py`：前后段、`[角色]`/`speaker:`/`角色：` 解析、角色历史聚合。

## 3. 个人资产系统

### 实现

- `app/assets.py`：
  - StarDict `.ifo/.idx/.dict` 读取（支持常见未压缩词典）。
  - 个人库 JSON 为编辑源，保存后自动编译为 StarDict 三件套。
  - 查询优先级：**个人库 > ja-zh > ja-ja > 日英兜底；不含 TB**（按你的补充要求）。
  - 日语活用还原（た/て/ます/ない/れる/られる/せる/させる/ば/よう 等常见形）。
  - 繁体释义内置常用字转换（展示层）；查询词不转换。
  - 个人库一词多译法、备注、标签、例句、状态（验证中/已验证/废弃）、读音。
  - KWIC 语感：个人库按词条索引，展示出处例句。
- `app/assets_ui.py`：
  - Ctrl+D（或顶栏词典按钮）：查询浮层，历史记录持久化。
  - Ctrl+Shift+D：捕获浮层，从选区预填词条/译法，一键入库。
  - 「词典路径」按钮打开 `~/.memodesk/assets/config.json`，可配置 StarDict 路径。
- 合规：零外部请求、零 LLM；捕获只写 `~/.memodesk/assets/`。

### 测试

- `tests/test_assets.py`：StarDict 往返、活用、繁简、优先级、个人库多译法、编译文件存在。

## 通用约束核对

| 约束 | 结果 |
|---|---|
| 数据不出本机 | 新模块无 HTTP/外部请求；仅本地文件/StarDict |
| 纯规则、零 LLM | 无任何 LLM 依赖 |
| 写路径唯一 | QA/语境只读；捕获只写本地个人库；未改 `WritePolicy` 入口 |
| 纯函数 JS + overlay + 能力探测 + JSON 外置 | `lint.js` 纯函数，规则 JSON，UI 浮层，能力缺失时显示/降级 |
| 离线测试 | 新增 4 个 fixture 测试，全量 66/66 |

## 验收步骤（真机）

1. 打开新编辑器文档，编辑一段使数字缺失 → 右栏出现 QA 警告、行内有标记。
2. 点「规则」关闭“数字” → 重跑后该警告消失，重启仍保留开关。
3. 点右栏 QA 警告 → 跳到对应行。
4. 查看主编辑区下方语境栏；点不同行，前后段更新。
5. 选中日语词 → Ctrl+D → 个人库/外部 StarDict 结果；确认无 TB 结果。
6. 选中原文/译文 → Ctrl+Shift+D → 入库；再 Ctrl+D 能查到。
7. 检查 `~/.memodesk/assets/personal.ifo/.idx/.dict` 已生成。

## 已知限制

- QA v1 行内标记按行，不精确到 token。
- 全半角只检查数字混用；标点检查默认关闭。
- 语境栏只读取已缓存段；项目 TM 角色聚合/补丁对比未实现。
- StarDict 不支持压缩 idx/MDict；词典路径需手动配置。
- 未做自动清洗外部词典版权/许可；用户自行确保词典文件合法。
