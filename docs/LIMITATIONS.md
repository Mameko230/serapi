# 已知限制与能力边界

## 平台

- 只在 Windows 10/11 + README 中列出的依赖组合上验证；其他环境需自行实测。
- Windows 上默认关闭 QtWebEngine Chromium sandbox（部分账户下 sandbox 起不来会白屏）。需要恢复时设置 `SERAPI_ENABLE_WEBENGINE_SANDBOX=1`。

## 桥接与 memoQ 页面

- 桥接依赖 memoQ WebTrans 页面结构；memoQ 升级后可能需要更新 `app/page_rules.json` 与契约 fixture。
- 新版 React 页面被 `hide()` 后不会继续渲染网格/编辑器，因此引擎页采用“停放到窗口可视区之外”，不是真正隐藏。
- 新版页面不响应 JS 合成的 Ctrl/Shift+Enter，确认/拒绝走 memoQ 行接口，不依赖合成快捷键。
- 新版 memoQ 不提供 contextId API；段信息中的上下文/注释/字数限制来自 **预览 HTML**，解析不到时只显示“新版不提供/—”，不会伪造 ID。
- 跟踪修改目前只做识别与写保护：开启跟踪修改、只读、锁定或缺少 rowId 时阻止整段写回，不支持在 Serapi 内接受/拒绝修订。
- 结构操作 API（lock/clear/split/join）已具备，但 UI 入口尚未开放；等真机冒烟明确后再接。

## 新版能力边界

### 实时 QA（1.2.0）

- v1 规则：数字一致性、Tag 差额、全半角数字混用、TB 术语未采用、行长/行数；规则可在右栏「实时 QA → 规则」逐条开关。
- Tag 差额按 `tag 名 + 类型 + 属性值 + kind` 比较，不比较 memoQ 按段分配的数字编号；换行 token 也参与计数。
- 只对当前段缓存 tokens 做检查；行内标记按“行”高亮，不自动改文，不进入写路径。
- 全半角 v1 只检查同一行内数字混用；标点检查默认关闭。
- 术语只检查带目标术语的 TB 命中；没有目标术语的 TB 条目无法判断，不报。

### 游戏语境（1.2.0）

- 前后各 2 段来自已缓存段列表；未加载的行不显示。
- speaker 优先来自预览 HTML 的 `話者・送信者`/`speaker`/`character`/`role` 等 `tr.other` 标签，其次解析源文 `[角色]`、`speaker:`、`角色：`；都取不到显示“—”。
- “角色既往译法”只聚合本会话已缓存行，不请求项目 TM；Patch 对照未实现（memoQ 读侧没有稳定的历史版本 API）。
- 全程只读，不触发写回。

### 预览附加信息（1.2.0）

- 依赖预览 HTML 的 `tr.other`；能解析的列包括注释/上下文/条件/字数限制，未知列保留为“其他”。
- 映射依据 `data-labIdx` + `preview/meta.rowIdsByStructuralIds`；映射异常时按预览顺序兜底，不保证分包/拆分文档完全准确。
- 字数限制按“整段译文上限”应用；与手工“每行/行数/逐行对比”限制相互独立。
- 预览解析失败不影响主编辑流程，只是没有预览信息。

### 个人资产（1.2.0）

- 查询优先级：个人库 > 配置的 ja-zh > ja-ja > zh-ja > 日英兜底；**不包含 TB**。
- 词典格式支持 StarDict `.ifo/.idx/.dict` 和 `.dict.dz`（不支持压缩 idx、不支持 MDict）；安装器可选组件装到程序目录 `dictionaries/`，便携版需手动指定路径。
- Jitendex（`.mdx/.mdd`）未内置；需要 MDict 支持时另行实现。
- 内置 Wiktionary 词典为 CC BY-SA 4.0，声明见 `dictionaries/THIRD_PARTY_NOTICES.md`。
- 个人库以 JSON 为编辑源，入库/修改后编译为 StarDict 三件套；例句只保存用户主动填写的短句。
- 日语活用还原覆盖常见形（た/て/ます/ない/れる/られる/せる/させる/ば/よう 等），不保证 Yomitan 全规则。
- 繁简转换内置常用字表，只用于释义展示；查询词不做 OpenCC 转换。
- 零外发、零 LLM；捕获只写本地文件。

## 新版编辑器能力

- 当前段读写：有改动时先 PUT 落库再确认；状态与左栏译文同步。
- 段列表：按行数据 API 分页，长文档行号连续；长跳先滚编辑器、列表窗口并行补；打开文档跟随 memoQ 上次编辑行；表头可按行状态过滤。
- TM/TB：命中查看、TB 详情（定义/示例/字段）、TM 插入（tag 按名字映射，原文没有的 tag 会略过；已离线验证）。
- 术语：TB 术语编辑（复用 QTermService，只改主术语/定义/示例；只读库拒绝写入）；Ctrl+Q 快捷添加（单库直加，多库选择/记住）；术语“添加”浮层（Ctrl+E）仍只支持旧版。
- 检索：Ctrl+K 语词检索（concordance）；Ctrl+H 打开 memoQ 原生查找替换。
- 过滤：原文/译文“包含”，支持正则；Ctrl+Shift+F 开关过滤栏。
- 段信息：注释只读；上下文/原始 ID 新版接口不提供。
- 编辑器：字号 12–28 可调；行距 1.7；行视觉可选 A 浅色斑马 / B 当前行聚焦（B 不压暗相邻行）。
- Tag 胶囊：编号取 `attrs.output`；长显值优先；已配置 tag 规则时按规则预览（换行/颜色/粗斜下划线/占位/隐藏），未配置规则的 tag 回退到 `#n 值`。
- 写保护：跟踪修改、只读、锁定、缺 rowId 时阻止整段写入；确认/拒绝前检查忙碌、行变、文档变。

## 旧版编辑器

- 术语编辑/添加、过滤、语词检索等旧版能力按现有实现工作；新版功能不保证在旧版全部可用。
